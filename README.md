# Resume Builder

A small, browser-based resume editor. Fill in the form and the page updates the
print preview as you type. There is no build step or account to create.

## Run it

Open `index.html` in a browser. Use **Print resume** to print or save a PDF.

## What’s here

- `index.html` — the form and preview
- `styles.css` — screen layout and print styles
- `app.js` — form events and preview rendering
